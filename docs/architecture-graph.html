The live turn — direct generation

Validate → attachments → gated recall (parallel, every leg best-effort) → prompt assembly → ONE inference call with tools → Response Engine. No planning layer; the deferred chain starts only after the reply.

Human Absolute Override — the only path to confirmed

GaiaChat lists the derived statements the machine is still weighing and moves one forward or lets it go. Confirm may supersede older statements; correct rewrites a settled one.

The lifecycle — six statuses

Corroborated is a machine tier; confirmed is human-only. Expired deletes nothing and quarantines nothing — a lapse is not a judgement, and evidence brings it back.

stateDiagram-v2

    proposed --> testing: first evidence
    proposed --> confirmed: a person settles it directly
    proposed --> rejected: let go (verwerp_bron mens)
    proposed --> expired: nothing arrived, 14 days (verwerp_bron verlopen)
    testing --> corroborated: soft-promotion — micro, C ≥ 0.80, no counter-evidence
    testing --> confirmed: HUMAN ONLY
    testing --> rejected: let go
    testing --> proposed: a person rewrites it
    corroborated --> confirmed: HUMAN ONLY
    corroborated --> testing: refine / contradiction
    corroborated --> rejected: let go
    expired --> testing: evidence arrives — a lapse is not a judgement
    expired --> confirmed: a person settles it
    expired --> rejected: let go
    expired --> proposed: a person rewrites it
    rejected --> testing: reopen — the only exit from that quarantine
    confirmed --> [*]
    rejected --> [*]

The three boundaries

These are load-bearing; a change that breaks one is a bug.

  1. Foundation = raw reality. A client that claims a status is refused (422). Observations only, and the store promotes nothing to fact by itself.
  2. Cognition = the lifecycle owner. It stores and books transitions; it never reasons. Logos proposes, belief formation forms statements from repeated ground, and the person settles them.
  3. Hindsight = the derived store. Rebuildable from Cognition with provenance, and recall lives there because Cognition has no vector search.
